# REGRAS DE REPOSITÓRIO E BACKUP (GITHUB)

## REPOSITÓRIO OFICIAL:
- URL Remota: `https://github.com/estreladamanha-jogos/time2-jogofinal.git`

## REGRAS DE COMMIT E VERSIONEAMENTO:
1. **Sempre que criar ou alterar um arquivo HTML/CSS/JS:** Salve a alteração e faça o commit imediatamente.
2. **Mensagens de Commit:** Use mensagens curtas, claras e numeradas/versionadas em português (ex: `v1.0 - Cria tela inicial do jogo`, `v1.1 - Adiciona movimentação do personagem`).
3. **Envio Automático:** Envie (`git push`) as alterações para a branch principal ou crie/atualize o Pull Request (PR) correspondente no repositório `time2-jogofinal.git`.
4. **Garantia de Backup:** Garanta que cada versão funcional do HTML fique gravada no histórico do repositório como um backup seguro.
